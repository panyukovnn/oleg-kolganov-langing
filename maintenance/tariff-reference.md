## Возможность интеграции калькулятора

Публичный адрес https://tariffs.77-91-113-145.nip.io/ проверен GET 15.09.2026: перенаправляет на /standalone/?ux=hybrid, страница отвечает 200. HEAD конечной страницы возвращает 404, поэтому для проверки доступности нужен GET. Реальный CSP содержит `frame-ancestors 'none'`: iframe сейчас блокируется.

1. Ссылка на существующий калькулятор — уже работает, расчёт остаётся в едином ядре.
2. Встраивание публичной страницы в iframe — сравнительно небольшой отдельный проект. На тестовом контуре разрешить в frame-ancestors только нужные origin, проверить остальные заголовки, адаптивность, высоту iframe и фокус с клавиатуры. При автоматическом изменении высоты через postMessage проверять origin. Сначала согласовать внешний вид на тесте. Private/Bitrix встраивать в публичный сайт нельзя.
3. Единый интерфейс прямо в Jekyll-странице — более значительная работа: frontend обращается к публичному серверу (`/standalone/api/bootstrap`, `/standalone/api/preview` по исходникам). Нужны договорённость об API, узкий CORS или собственный reverse proxy, обработка ошибок, проверка входных параметров и сквозные тесты с эталонными расчётами. GitHub Pages сам Node-сервер не запускает. Формулы в JavaScript сайта не дублировать.

Рекомендация: после приёмки справочника отдельно подготовить iframe-вариант на тестовом контуре и выбрать внешний вид. Сейчас изменения калькулятора и его сервера не выполнялись.
